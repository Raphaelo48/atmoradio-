# Atmospheric Web Radio (Fabric mod)

## Важно прочитать перед сборкой
1. **Версия Minecraft "1.21.11" в задании не существует** (актуальная линейка — 1.21.x,
   последняя на сегодня ~1.21.4-1.21.8 в зависимости от даты). Проект настроен на
   `1.21.1` в `gradle.properties` — поменяйте `minecraft_version`/`yarn_mappings` на
   нужную вам версию с https://fabricmc.net/develop/.
2. **"API SoundCloud"** без официального партнёрского доступа сейчас закрыт для новых
   приложений, а обход авторизации нарушает ToS — такое я не реализовывал. Вместо
   этого сделан подключаемый интерфейс `TrackProvider` (`client/gui/TrackProvider.java`).
   По умолчанию используется публичный iTunes Search API (легально, без ключа,
   отдаёт прямые ссылки на превью-mp3) — это демонстрирует весь пайплайн
   "поиск → стрим → 3D-звук". Чтобы получать полноформатные треки легально,
   подключите свой источник (Jamendo API с ключом, Free Music Archive, собственный
   backend) — замените тело `TrackProvider.itunesPreview()` или добавьте новую
   реализацию интерфейса.
3. Любой прямой HTTP(S) URL на MP3-поток (включая постоянные интернет-радиостанции)
   тоже можно скормить в `RadioSoundManager.play(pos, url, title)` — для этого
   декодер не завязан на iTunes, он просто читает байты по URL.

## Архитектура
- `block/RadioBlock.java`, `block/RadioBlockEntity.java` — блок и его состояние
  (что сейчас играет), синхронизируется по сети новым игрокам.
- `network/RadioNetworking.java` — все пакеты (S2C Play/Stop, C2S RequestPlay/Stop,
  OpenSearch).
- `client/gui/RadioSearchScreen.java` — ванильный GUI: поиск, список, Play/Stop.
- `client/gui/TrackProvider.java` — абстракция поиска треков (плагин-точка).
- `client/sound/Mp3HttpAudioStream.java` — потоковый MP3-декодер (JLayer) поверх
  HTTP-соединения, без записи на диск: данные декодируются кадр за кадром по мере
  поступления и сразу превращаются в PCM.
- `client/sound/RadioSoundManager.java` — сердце 3D-звука:
  - собственный контекст OpenAL (чтобы не упираться в ограничения ванильного
    SoundSystem, который не рассчитан на произвольные живые потоки);
  - `AL_LINEAR_DISTANCE_CLAMPED` + `AL_REFERENCE_DISTANCE`/`AL_MAX_DISTANCE` = честное
    затухание громкости от 0 до 36 блоков;
  - позиция/ориентация слушателя обновляется из камеры игрока каждый тик →
    естественная стереопанорама при повороте головы, это даёт сам OpenAL;
  - окклюзия: raycast блоками между ухом игрока и радио; при препятствии
    приглушается громкость и, если железо/драйвер поддерживает `ALC_EXT_EFX`,
    навешивается low-pass фильтр (`AL_LOWPASS_GAINHF`), который реально срезает
    высокие частоты — "глухой" звук из соседней комнаты;
  - двойная/четверная буферизация (`AL_BUFFERS_QUEUED`/`PROCESSED`) — классический
    стриминговый паттерн OpenAL, PCM докачивается по мере проигрывания.
  - частицы `minecraft:note` вылетают из блока каждые ~8 тиков, пока радио играет.
- Stop (кнопка в GUI) или разрушение блока → `RadioBlockEntity.stopAndBroadcast()` →
  пакет Stop всем клиентам → `RadioSoundManager.stop(pos)` сразу обрывает источник
  и закрывает HTTP-соединение.

## Известные ограничения / что доработать для продакшена
- EFX low-pass — не на всех платформах/драйверах доступен (`ALC_EXT_EFX` опционален);
  есть фоллбек на чистое приглушение громкости.
- Окклюзия сейчас — один луч от глаз до центра блока; для более плавного эффекта
  стоит усреднять несколько лучей или считать толщину препятствия.
- Нет анти-чит проверки дистанции игрок-блок при приёме `RequestPlayPayload` на
  сервере — добавьте проверку `player.getPos().isInRange(pos, X)` перед стартом.
- JLayer декодирует только MP3. Для OGG/AAC потоков нужен другой декодер
  (javax.sound для WAV/AIFF "из коробки", для AAC — потребуется доп. библиотека).
- Собственный OpenAL-контекст звучит параллельно основному — громкость радио не
  привязана к ползункам настроек звука Minecraft (Master/Music/etc). Для интеграции
  с настройками звука игры нужно либо читать `GameOptions` вручную и домножать
  гейн, либо (сложнее, но "правильнее") разбираться с внутренним `SoundSystem`
  через миксины вместо отдельного контекста.
